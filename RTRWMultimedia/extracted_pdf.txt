A.​INSTALASI SQL SERVER EXPRESS​
Tujuan Praktikum 
Setelah menyelesaikan kegiatan ini siswa mampu: 
1.​ Menginstal SQL Server Express. 
2.​ Membuat Instance Database Engine. 
3.​ Memastikan SQL Server berjalan dengan baik. 
4.​ Menyiapkan database untuk aplikasi RT/RW. 
1. Mengenal SQL Server Express 
SQL Server Express merupakan Database Management System (DBMS) yang dikembangkan 
oleh Microsoft dan dapat digunakan secara gratis. 
Pada proyek ini SQL Server digunakan untuk menyimpan: 
●​ Data warga 
●​ Data iuran 
●​ Data pengumuman 
●​ Data pengguna aplikasi 
●​ Data laporan 
2. Persiapan Instalasi 
Sebelum melakukan instalasi, pastikan komputer memiliki spesifikasi minimum: 
Komponen 
Minimal 
Sistem Operasi 
Windows 10 64 Bit 
RAM 
4 GB 
Harddisk 
10 GB kosong 
Processor 
Intel Core i3 Generasi 6 atau setara 
.NET Framework 
4.8 
 


=== PAGE 2 ===
3. Mengunduh SQL Server Express 
a.​ Buka browser kemudian kunjungi: 
Microsoft SQL Server Express 
b.​ Pilih: 
SQL Server 2022 Express 
c.​ Kemudian klik: Download Now  
d.​ Simpan file installer pada folder: D:\Installer\SQLServer  
 
 
4. Menjalankan Installer  
a.​ Klik dua kali file: SQL2022-SSEI-Expr.exe 
b.​ Maka akan muncul jendela instalasi SQL Server.  
c.​ Pilih: Basic 
Penjelasan : Mode Basic akan melakukan konfigurasi otomatis sehingga lebih mudah 
digunakan. 
 
5. Menyetujui Lisensi 
a.​ Centang: Accept Microsoft License Terms 
b.​ Klik: Install 
c.​ Tunggu proses instalasi hingga selesai 
 
6. Menyelesaikan Instalasi  
a.​ Jika berhasil akan muncul informasi:Installation Successful 
b.​ Catat informasi berikut: Server Name (Contoh:DESKTOP-01\SQLEXPRESS) 
Server Name ini akan digunakan saat menghubungkan aplikasi dengan 
database  
7. Memeriksa Service SQL Server  
a.​ Tekan: Windows + R 
b.​ Ketik: services.msc 
c.​ Klik: OK 
d.​ Cari service:  SQL Server (SQLEXPRESS).  
e.​ Pastikan status:Running 
f.​ Jika belum berjalan: Klik kanan →Start
